This is a good architecture because ESP-NOW itself is carried in vendor-specific 802.11 action frames, so using it during the RF measurement would contaminate exactly what we're trying to characterize. Espressif's raw esp_wifi_80211_tx() API supports action frames and non-QoS data frames, and its default raw-frame rate is 1 Mbps; the TX rate can be configured separately. 

The orchestration below uses a control channel, normally channel 1. Every measurement proceeds:

CONTROL CHANNEL
      │
      │ PREPARE
      │ ACK
      │ GO
      ▼
TARGET RF CHANNEL
      │
      │ fixed guard
      │ fixed measurement window
      │ no ESP-NOW
      ▼
CONTROL CHANNEL
      │
      │ RESULT
      ▼
next phase

This is also important because ESP-NOW communication requires the nodes to be on the same Wi-Fi channel; esp_wifi_set_channel() is the low-level API used to move them between channels. 

Sweep structure

I would run four phases per RF channel:

REF_V_TX
    reference V antenna -> test antenna + test reference antenna

REF_H_TX
    reference H antenna -> test antenna + test reference antenna

TEST_A_TX
    test antenna -> reference V + reference H

TEST_R_TX
    test reference antenna -> reference V + reference H

So each channel gives you the full directional 2×2 matrix:

RX
             Test      Test-Ref
TX
Ref-V         Hvv       Hvr
Ref-H         Hhv       Hhr

and reverse:

                 RX
             Ref-V     Ref-H
TX
Test          ...       ...
Test-Ref      ...       ...

For every RX radio we accumulate:

CSI frame count
RSSI min/max
RSSI mean
RSSI standard deviation
CSI complex I/Q averages
number of usable CSI bins

The detailed CSI accumulation is done in the callback only; Espressif specifically recommends keeping the CSI callback short and moving heavier processing outside it.

Reference-node master firmware

This is intentionally written around the low-level IDF APIs exposed by Arduino-ESP32, rather than Arduino's high-level Wi-Fi abstractions.

It assumes an ESP32-class target running an Arduino-ESP32 release based on IDF 5.x. The current ESP-NOW receive callback uses esp_now_recv_info_t, as in the current IDF API.

struct CsiAccumulator {

    volatile uint32_t frames = 0;

    volatile uint32_t packets = 0;

    volatile int32_t rssiSum = 0;

    volatile uint32_t rssiSumSq = 0;

    volatile int8_t rssiMin = 127;

    volatile uint32_t pairCountTotal = 0;

    int32_t sumI[MAX_CSI_PAIRS];

    int32_t sumQ[MAX_CSI_PAIRS];

    uint16_t binCount[MAX_CSI_PAIRS];
};

// This lock protects only short accumulator operations.

static portMUX_TYPE gCsiMux = portMUX_INITIALIZER_UNLOCKED;


// ============================================================
// CSI RESET
// ============================================================

static void resetCsiAccumulator()
{
    portENTER_CRITICAL(&gCsiMux);

    memset(&gCsi, 0, sizeof(gCsi));

    gCsi.rssiMin = 127;
    gCsi.rssiMax = -127;

    portEXIT_CRITICAL(&gCsiMux);
}


// ============================================================
// CSI CALLBACK
// ============================================================
//
// IMPORTANT:
// Do not Serial.print here.
// Do not allocate memory.
// Do not perform expensive DSP.
//
// Espressif executes this in the Wi-Fi task.
// ============================================================

static void IRAM_ATTR onCsiData(
    void *ctx,
    wifi_csi_info_t *data)
{
    if (data == nullptr) {
        return;
    }

    if (data->buf == nullptr) {
        return;
    }

    const int len = data->len;

    if (len < 2) {
        return;
    }

    const int pairCount =
        min(
            len / 2,
            static_cast<int>(MAX_CSI_PAIRS)
        );

    const int8_t rssi =
        data->rx_ctrl.rssi;

    portENTER_CRITICAL_ISR(&gCsiMux);

    gCsi.frames++;

    gCsi.rssiSum += rssi;

    gCsi.rssiSumSq +=
        static_cast<uint32_t>(rssi * rssi);

    if (rssi < gCsi.rssiMin) {
        gCsi.rssiMin = rssi;
    }

    if (rssi > gCsi.rssiMax) {
        gCsi.rssiMax = rssi;
    }

    gCsi.pairCountTotal += pairCount;

    for (int i = 0; i < pairCount; ++i) {

        // ESP-IDF CSI representation is complex I/Q data.
        //
        // On the classic ESP32 layout we treat the first byte
        // as imaginary and the second as real.
        //
        // This should be verified for the exact ESP32 target
        // and IDF revision used for the final instrument.

        const int8_t imag =
            data->buf[2 * i];

        const int8_t real =
            data->buf[2 * i + 1];

        gCsi.sumI[i] += real;

        gCsi.sumQ[i] += imag;

        gCsi.binCount[i]++;
    }

    portEXIT_CRITICAL_ISR(&gCsiMux);
}

static void initWifi()
{
    WiFi.mode(WIFI_STA);

    WiFi.disconnect(true, true);

    delay(50);

    esp_err_t err;

    err = esp_wifi_set_ps(WIFI_PS_NONE);

    if (err != ESP_OK) {
        Serial.printf(
            "WARNING esp_wifi_set_ps: %s\n",
            esp_err_to_name(err)
        );
    }

    err = esp_wifi_set_channel(
        CONTROL_CHANNEL,
        WIFI_SECOND_CHAN_NONE
    );

    if (err != ESP_OK) {
        Serial.printf(
            "ERROR esp_wifi_set_channel: %s\n",
            esp_err_to_name(err)
        );
        while (true) {
            delay(1000);
        }
    }

    // Enable promiscuous mode so CSI can be collected
    // without needing an AP connection.

    err = esp_wifi_set_promiscuous(true);

    if (err != ESP_OK) {
        Serial.printf(
            "ERROR promiscuous: %s\n",
            esp_err_to_name(err)
        );
        while (true) {
            delay(1000);
        }
    }

    // CSI callback

    err = esp_wifi_set_csi_rx_cb(
        onCsiData,
        nullptr
    );

    if (err != ESP_OK) {
        Serial.printf(
            "ERROR CSI callback: %s\n",
            esp_err_to_name(err)
        );
        while (true) {
            delay(1000);
        }
    }

    wifi_csi_config_t csiConfig{};

    csiConfig.lltf_en = true;
    csiConfig.htltf_en = true;
    csiConfig.stbc_htltf2_en = true;

    csiConfig.ltf_merge_en = false;

    csiConfig.channel_filter_en = false;

    csiConfig.manu_scale = false;

    csiConfig.shift = 0;

    err = esp_wifi_set_csi_config(
        &csiConfig
    );

    if (err != ESP_OK) {
        Serial.printf(
            "ERROR CSI config: %s\n",
            esp_err_to_name(err)
        );
        while (true) {
            delay(1000);
        }
    }

    err = esp_wifi_set_csi(true);

    if (err != ESP_OK) {
        Serial.printf(
            "ERROR CSI enable: %s\n",
            esp_err_to_name(err)
        );
        while (true) {
            delay(1000);
        }
    }

    // Conservative starting TX power.
    //
    // esp_wifi_set_max_tx_power() uses quarter-dBm units.
    //
    // Change this only after deciding the legal EIRP for the
    // actual antenna installation.

    err = esp_wifi_set_max_tx_power(78);

    if (err != ESP_OK) {
        Serial.printf(
            "WARNING TX power: %s\n",
            esp_err_to_name(err)
        );
    }
}

static void onEspNowReceive(
    const esp_now_recv_info_t *info,
    const uint8_t *data,
    int len)
{
    if (info == nullptr ||
        info->src_addr == nullptr ||
        data == nullptr) {
        return;
    }

    if (len <= 0 ||
        len > static_cast<int>(
            sizeof(EspNowRxMessage::data))) {
        return;
    }

    if (memcmp(
            info->src_addr,
            TEST_MASTER_MAC,
            6) != 0) {
        return;
    }

    EspNowRxMessage message{};

    memcpy(
        message.srcMac,
        info->src_addr,
        6
    );

    message.length = len;

    memcpy(
        message.data,
        data,
        len
    );

    if (gEspNowRxQueue != nullptr) {

        xQueueSend(
            gEspNowRxQueue,
            &message,
            0
        );
    }
}


static bool addEspNowPeer(
    const uint8_t mac[6])
{
    if (esp_now_is_peer_exist(mac)) {
        return true;
    }

    esp_now_peer_info_t peer{};

    memcpy(
        peer.peer_addr,
        mac,
        6
    );

    peer.channel = CONTROL_CHANNEL;

    peer.ifidx = WIFI_IF_STA;

    peer.encrypt = false;

    esp_err_t err =
        esp_now_add_peer(&peer);

    if (err != ESP_OK) {

        Serial.printf(
            "esp_now_add_peer failed: %s\n",
            esp_err_to_name(err)
        );

        return false;
    }

    return true;
}


static void initEspNow()
{
    gEspNowRxQueue =
        xQueueCreate(
            8,
            sizeof(EspNowRxMessage)
        );

    if (gEspNowRxQueue == nullptr) {

        Serial.println(
            "FATAL: ESP-NOW queue allocation failed"
        );

        while (true) {
            delay(1000);
        }
    }

    esp_err_t err =
        esp_now_init();

    if (err != ESP_OK) {

        Serial.printf(
            "FATAL esp_now_init: %s\n",
            esp_err_to_name(err)
        );

        while (true) {
            delay(1000);
        }
    }

    err =
        esp_now_set_pmk(
            ESPNOW_PMK
        );

    if (err != ESP_OK) {

        Serial.printf(
            "WARNING esp_now_set_pmk: %s\n",
            esp_err_to_name(err)
        );
    }

    esp_now_register_recv_cb(
        onEspNowReceive
    );

    if (!addEspNowPeer(TEST_MASTER_MAC)) {

        while (true) {
            delay(1000);
        }
    }
}

// ============================================================
// WAIT FOR REMOTE MESSAGE
// ============================================================

static bool waitRemote(
    RemoteMsgType desiredType,
    uint32_t runId,
    uint16_t testId,
    uint32_t timeoutMs,
    EspNowRxMessage &result)
{
    const uint32_t start =
        millis();

    while ((millis() - start) < timeoutMs) {

        if (xQueueReceive(
                gEspNowRxQueue,
                &result,
                pdMS_TO_TICKS(10)) == pdTRUE) {

            if (result.length <
                sizeof(uint16_t) +
                2) {
                continue;
            }

            const uint8_t type =
                result.data[3];

            if (type !=
                static_cast<uint8_t>(desiredType)) {
                continue;
            }

            if (desiredType ==
                RemoteMsgType::ACK) {

                if (result.length <
                    sizeof(RemoteAck)) {
                    continue;
                }

                const RemoteAck *ack =
                    reinterpret_cast<
                        const RemoteAck *>(
                            result.data
                        );

                if (ack->magic != 0x5246) {
                    continue;
                }

                if (ack->runId != runId ||
                    ack->testId != testId) {
                    continue;
                }

                return true;
            }

            if (desiredType ==
                RemoteMsgType::RESULT) {

                if (result.length <
                    sizeof(RemoteResultPacket)) {
                    continue;
                }

                const RemoteResultPacket *packet =
                    reinterpret_cast<
                        const RemoteResultPacket *>(
                            result.data
                        );

                if (packet->magic != 0x5246) {
                    continue;
                }

                if (packet->runId != runId ||
                    packet->testId != testId) {
                    continue;
                }

                return true;
            }
        }
    }

    return false;
}


// ============================================================
// LOCAL SERIAL CRC16
// ============================================================

static uint16_t crc16(
    const uint8_t *data,
    size_t len)
{
    uint16_t crc = 0xFFFF;

    for (size_t i = 0; i < len; ++i) {

        crc ^= data[i];

        for (uint8_t j = 0; j < 8; ++j) {

            if (crc & 1) {
                crc =
                    (crc >> 1) ^
                    0xA001;
            }
            else {
                crc >>= 1;
            }
        }
    }

    return crc;
}


// ============================================================
// LOCAL SERIAL TX
// ============================================================

static void sendLocalFrame(
    LocalCmdType type,
    const uint8_t *payload,
    uint8_t length)
{
    if (length > LOCAL_MAX_PAYLOAD) {
        return;
    }

    LocalFrameHeader header;

    header.magic1 = LOCAL_MAGIC1;
    header.magic2 = LOCAL_MAGIC2;
    header.type =
        static_cast<uint8_t>(type);
    header.length = length;

    Serial1.write(
        reinterpret_cast<uint8_t *>(&header),
        sizeof(header)
    );

    if (length > 0 &&
        payload != nullptr) {

        Serial1.write(
            payload,
            length
        );
    }

    uint16_t crc = crc16(
        reinterpret_cast<const uint8_t *>(
            &header),
        sizeof(header)
    );

    if (length > 0 &&
        payload != nullptr) {

        // Combine CRC without allocating a second buffer.
        for (uint8_t i = 0; i < length; ++i) {

            uint8_t b = payload[i];

            crc ^= b;

            for (uint8_t j = 0; j < 8; ++j) {

                if (crc & 1)
                    crc =
                        (crc >> 1) ^
                        0xA001;
                else
                    crc >>= 1;
            }
        }
    }

    Serial1.write(
        reinterpret_cast<uint8_t *>(&crc),
        sizeof(crc)
    );

    Serial1.flush();
}

// ============================================================

// ============================================================

static uint16_t buildTestFrame(
    uint8_t *frame,
    uint32_t sequence,
    Phase phase)
{
    /*
     * 802.11 action frame:
     *
     * FC
     * Duration
     * DA
     * SA
     * BSSID
     * Sequence
     * Category
     * OUI
     * Vendor type
     * Custom payload
     */

    uint16_t p = 0;

    const uint16_t frameControl =
        0x00D0; // Management Action

    memcpy(
        frame + p,
        &frameControl,
        sizeof(frameControl)
    );

    p += 2;

    uint16_t duration = 0;

    memcpy(
        frame + p,
        &duration,
        sizeof(duration)
    );

    p += 2;

    // Broadcast DA

    memset(
        frame + p,
        0xFF,
        6
    );

    p += 6;

    // Source MAC

    uint8_t ownMac[6];

    esp_wifi_get_mac(
        WIFI_IF_STA,
        ownMac
    );

    memcpy(
        frame + p,
        ownMac,
        6
    );

    p += 6;

    // Broadcast BSSID

    memset(
        frame + p,
        0xFF,
        6
    );

    p += 6;

    // Sequence control = driver generated.

    uint16_t sequenceControl = 0;

    memcpy(
        frame + p,
        &sequenceControl,
        2
    );

    p += 2;

    // Vendor-specific action category.

    frame[p++] = 127;

    // Test OUI.
    //
    // Deliberately not pretending to be an Espressif
    // ESP-NOW frame.

    frame[p++] = 0xDE;
    frame[p++] = 0xAD;
    frame[p++] = 0xBE;

    frame[p++] = 0x01; // test frame version

    // Magic

    frame[p++] = 0x52;
    frame[p++] = 0x46;
    frame[p++] = 0x54;
    frame[p++] = 0x53;

    // Run ID

    memcpy(
        frame + p,
        &gRunId,
        sizeof(gRunId)
    );

    p += sizeof(gRunId);

    // Test ID

    memcpy(
        frame + p,
        &gTestId,
        sizeof(gTestId)
    );

    p += sizeof(gTestId);

    // Phase

    frame[p++] =
        static_cast<uint8_t>(phase);

    // Sequence

    memcpy(
        frame + p,
        &sequence,
        sizeof(sequence)
    );

    p += sizeof(sequence);

    // Remaining deterministic filler.

    while (p < 24 +
                  1 + 3 + 1 + 4 +
                  4 + 2 + 1 + 4) {

        frame[p++] = 0xA5;
    }

    return p;
}

// ============================================================
// MASTER RESULT CREATION
// ============================================================

static RFResultSummary buildMasterResult(
    RadioMode mode,
    uint32_t packets,
    uint32_t txErrors)
{
    RFResultSummary result{};

    result.mode =
        static_cast<uint8_t>(mode);

    result.packets = packets;

    result.txErrors = txErrors;

    portENTER_CRITICAL(&gCsiMux);

    result.csiFrames =
        static_cast<uint16_t>(
            min<uint32_t>(
                gCsi.frames,
                UINT16_MAX
            )
        );

    result.csiValid =
        (gCsi.frames > 0) ? 1 : 0;

    result.rssiSum =
        gCsi.rssiSum;

    result.rssiSumSq =
        gCsi.rssiSumSq;

    result.rssiMin =
        gCsi.rssiMin;

    result.rssiMax =
        gCsi.rssiMax;

    const uint16_t actualPairs =
        static_cast<uint16_t>(
            min<uint32_t>(
                MAX_CSI_PAIRS,
                gCsi.pairCountTotal /
                    max<uint32_t>(
                        1,
                        gCsi.frames
                    )
            )
        );

    result.csiPairs =
        actualPairs;

    for (
        uint8_t out = 0;
        out < EXPORT_CSI_BINS;
        ++out
    ) {

        uint16_t sourceIndex;

        if (actualPairs <= 1) {
            sourceIndex = 0;
        }
        else {
            sourceIndex =
                static_cast<uint16_t>(
                    (
                        static_cast<uint32_t>(
                            out
                        ) *
                        (actualPairs - 1)
                    ) /
                    (EXPORT_CSI_BINS - 1)
                );
        }

        const uint16_t count =
            gCsi.binCount[sourceIndex];

        if (count == 0) {
            result.avgI[out] = 0;
            result.avgQ[out] = 0;
        }
        else {
            result.avgI[out] =
                static_cast<int8_t>(
                    gCsi.sumI[sourceIndex] /
                    static_cast<int32_t>(count)
                );

            result.avgQ[out] =
                static_cast<int8_t>(
                    gCsi.sumQ[sourceIndex] /
                    static_cast<int32_t>(count)
                );
        }
    }

    portEXIT_CRITICAL(&gCsiMux);

    return result;
}


// ============================================================
// PRINT RESULT
// ============================================================

static void printResult(
    const char *name,
    const RFResultSummary &r)
{
    float meanRssi = NAN;
    float rmsRssi  = NAN;
    float stdRssi  = NAN;

    if (r.csiFrames > 0) {

        meanRssi =
            static_cast<float>(
                r.rssiSum
            ) /
            r.csiFrames;

        const float meanSq =
            static_cast<float>(
                r.rssiSumSq
            ) /
            r.csiFrames;

        rmsRssi =
            sqrtf(
                max(
                    0.0f,
                    meanSq
                )
            );

        const float variance =
            max(
                0.0f,
                meanSq -
                meanRssi * meanRssi
            );

        stdRssi =
            sqrtf(variance);
    }

    Serial.printf(
        "RESULT,"
        "run=%lu,"
        "test=%u,"
        "channel=%u,"
        "phase=%u,"
        "radio=%s,"
        "mode=%u,"
        "frames=%u,"
        "packets=%lu,"
        "txerr=%lu,"
        "rssi=%.2f,"
        "rms=%.2f,"
        "std=%.2f,"
        "min=%d,"
        "max=%d\n",

        static_cast<unsigned long>(gRunId),
        gTestId,
        gCurrentChannel,
        static_cast<unsigned>(gCurrentPhase),

        name,

        r.mode,

        r.csiFrames,

        static_cast<unsigned long>(
            r.packets
        ),

        static_cast<unsigned long>(
            r.txErrors
        ),

        meanRssi,
        rmsRssi,
        stdRssi,

        r.rssiMin,
        r.rssiMax
    );

    Serial.print("CSI,");

    Serial.printf(
        "%lu,%u,%u,%u,%s",
        static_cast<unsigned long>(gRunId),
        gTestId,
        gCurrentChannel,
        static_cast<unsigned>(gCurrentPhase),
        name
    );

    for (
        uint8_t i = 0;
        i < EXPORT_CSI_BINS;
        ++i
    ) {

        Serial.printf(
            ",%d,%d",
            r.avgI[i],
            r.avgQ[i]
        );
    }

    Serial.println();
}


// ============================================================
// RUN LOCAL TRANSMISSION
// ============================================================

static void runMasterTx(
    Phase phase)
{
    const uint64_t startUs =
        esp_timer_get_time();

    const uint64_t endUs =
        startUs +
        static_cast<uint64_t>(
            RF_WINDOW_MS
        ) *
        1000ULL;

    uint64_t nextTx =
        startUs;

    uint32_t sent = 0;
    uint32_t errors = 0;

    while (
        esp_timer_get_time() <
        endUs) {

        const uint64_t now =
            esp_timer_get_time();

        if (now < nextTx) {

            const uint64_t waitUs =
                nextTx - now;

            if (waitUs > 1000) {
                delay(
                    static_cast<uint32_t>(
                        waitUs / 1000
                    )
                );
            }
            else {
                delayMicroseconds(
                    static_cast<uint32_t>(
                        waitUs
                    )
                );
            }

            continue;
        }

        if (sendRfPacket(
                sent,
                phase)) {

            ++sent;
        }
        else {
            ++errors;
        }

        nextTx += TX_INTERVAL_US;
    }

    RFResultSummary result =
        buildMasterResult(
            RadioMode::TX,
            sent,
            errors
        );

    printResult(
        "REF_MASTER",
        result
    );
}


// ============================================================
// MASTER RX WINDOW
// ============================================================

static RFResultSummary runMasterRx()
{
    const uint64_t startUs =
        esp_timer_get_time();

    const uint64_t endUs =
        startUs +
        static_cast<uint64_t>(
            RF_WINDOW_MS
        ) *
        1000ULL;

    while (
        esp_timer_get_time() <
        endUs) {

        delay(1);
    }

    return buildMasterResult(
        RadioMode::RX,
        0,
        0
    );
}


// ============================================================
// REMOTE PREPARE
// ============================================================

static bool remotePrepare()
{
    RemoteCommand command{};

    command.magic = 0x5246;

    command.version = 1;

    command.type =
        static_cast<uint8_t>(
            RemoteMsgType::PREPARE
        );

    command.runId = gRunId;

    command.testId = gTestId;

    command.phase =
        static_cast<uint8_t>(
            gCurrentPhase
        );

    command.channel =
        gCurrentChannel;

    command.durationMs =
        RF_WINDOW_MS;

    command.guardMs =
        RF_GUARD_MS;

    command.txIntervalUs =
        TX_INTERVAL_US;

    // Clear stale packets.

    xQueueReset(
        gEspNowRxQueue
    );

    for (uint8_t retry = 0;
         retry < 3;
         ++retry) {

        if (!sendRemote(
                &command,
                sizeof(command))) {
            continue;
        }

        EspNowRxMessage response{};

        if (waitRemote(
                RemoteMsgType::ACK,
                gRunId,
                gTestId,
                150,
                response)) {

            const RemoteAck *ack =
                reinterpret_cast<
                    const RemoteAck *>(
                        response.data
                    );

            if (ack->ackedType ==
                    static_cast<uint8_t>(
                        RemoteMsgType::PREPARE) &&
                ack->status == 0) {

                return true;
            }
        }
    }

    return false;
}

// REMOTE GO
// ============================================================

static bool remoteGo()
{
    RemoteCommand command{};

    command.magic = 0x5246;

    command.version = 1;

    command.type =
        static_cast<uint8_t>(
            RemoteMsgType::GO
        );

    command.runId = gRunId;

    command.testId = gTestId;

    command.phase =
        static_cast<uint8_t>(
            gCurrentPhase
        );

    command.channel =
        gCurrentChannel;

    command.durationMs =
        RF_WINDOW_MS;

    command.guardMs =
        RF_GUARD_MS;

    command.txIntervalUs =
        TX_INTERVAL_US;

    if (!sendRemote(
            &command,
            sizeof(command))) {

        return false;
    }

    EspNowRxMessage response{};

    if (!waitRemote(
            RemoteMsgType::ACK,
            gRunId,
            gTestId,
            200,
            response)) {

        return false;
    }

    const RemoteAck *ack =
        reinterpret_cast<
            const RemoteAck *>(
                response.data
            );

    if (ack->ackedType !=
        static_cast<uint8_t>(
            RemoteMsgType::GO
        )) {

        return false;
    }

    return ack->status == 0;
}

    return true;
}

// ============================================================
// PHASE TEST
// ============================================================

static bool runPhase(
    Phase phase,
    uint8_t channel)
{
    gCurrentPhase = phase;

    gCurrentChannel = channel;

    ++gTestId;

    Serial.printf(
        "\n=== TEST %u / channel %u / phase %u ===\n",
        gTestId,
        channel,
        static_cast<unsigned>(phase)
    );

    // --------------------------------------------------------
    // Always return to the control channel before orchestration.
    // --------------------------------------------------------

    if (!setRadioChannel(
            CONTROL_CHANNEL)) {

        return false;
    }

    // --------------------------------------------------------
    // Determine what local H radio must do.
    // --------------------------------------------------------

    switch (phase) {

        case Phase::REF_V_TX:
            // H radio receives? No.
            // It is idle.
            break;

        case Phase::REF_H_TX:
            // H radio transmits.
            break;

        case Phase::TEST_A_TX:
        case Phase::TEST_R_TX:
            // H radio receives.
            break;
    }

    // --------------------------------------------------------
    // Prepare remote test node.
    // --------------------------------------------------------

    if (!remotePrepare()) {

        Serial.println(
            "ERROR: remote PREPARE failed"
        );

        return false;
    }

    // --------------------------------------------------------
    // Prepare local H radio.
    // --------------------------------------------------------

    prepareLocalSlave(
        phase,
        channel
    );

    delay(20);

    // --------------------------------------------------------
    // Reset local CSI before GO.
    // --------------------------------------------------------

    resetCsiAccumulator();

    // --------------------------------------------------------
    // Issue GO over ESP-NOW.
    //
    // The remote node acknowledges BEFORE switching.
    // --------------------------------------------------------

    if (!remoteGo()) {

        Serial.println(
            "ERROR: remote GO failed"
        );

        return false;
    }

    // --------------------------------------------------------
    // Start local H radio.
    // --------------------------------------------------------

    goLocalSlave(
        phase,
        channel
    );

    // --------------------------------------------------------
    // Move this radio to RF test channel.
    // --------------------------------------------------------

    if (!setRadioChannel(
            channel)) {

        return false;
    }

    // --------------------------------------------------------
    // Common guard.
    //
    // During this period remote/local slaves are also
    // switching and arming.
    // --------------------------------------------------------

    delay(RF_GUARD_MS);

    gPhaseRunning = true;

    RFResultSummary masterResult{};

    switch (phase) {

        // ----------------------------------------------------
        // Reference V TX
        // ----------------------------------------------------

        case Phase::REF_V_TX:

            runMasterTx(
                phase
            );

            break;

        // ----------------------------------------------------
        // Reference H TX
        // ----------------------------------------------------

        case Phase::REF_H_TX:

            // Master is RX.
            masterResult =
                runMasterRx();

            break;

        // ----------------------------------------------------
        // Test antenna TX
        // ----------------------------------------------------

        case Phase::TEST_A_TX:

            masterResult =
                runMasterRx();

            break;

        // ----------------------------------------------------
        // Test reference antenna TX
        // ----------------------------------------------------

        case Phase::TEST_R_TX:

            masterResult =
                runMasterRx();

            break;
    }

    gPhaseRunning = false;

    // --------------------------------------------------------
    // Return to control channel.
    // --------------------------------------------------------

    delay(
        RF_RETURN_GUARD_MS
    );

    if (!setRadioChannel(
            CONTROL_CHANNEL)) {

        return false;
    }

    // --------------------------------------------------------
    // Remote result.
    // --------------------------------------------------------

    RemoteResultPacket remoteResult{};

    if (!getRemoteResult(
            remoteResult)) {

        Serial.println(
            "WARNING: remote result timeout"
        );
    }
    else {

        printResult(
            "REMOTE_RADIO0",
            remoteResult.radio0
        );

        printResult(
            "REMOTE_RADIO1",
            remoteResult.radio1
        );
    }

    // --------------------------------------------------------
    // Local H result.
    // --------------------------------------------------------

    RFResultSummary localResult{};

    if (getLocalSlaveResult(
            localResult,
            100)) {

        printResult(
            "LOCAL_H",
            localResult
        );
    }

    // --------------------------------------------------------
    // Print master RX result if applicable.
    // --------------------------------------------------------

    switch (phase) {

        case Phase::REF_H_TX:
        case Phase::TEST_A_TX:
        case Phase::TEST_R_TX:

            printResult(
                "REF_MASTER_V",
                masterResult
            );

            break;

        case Phase::REF_V_TX:

            // Master was transmitter.
            break;
    }

    return true;
}


// ============================================================
// FULL SWEEP
// ============================================================

static void runSweep()
{
    gRunId++;

    gTestId = 0;

    Serial.println(
        "\n\n================================"
    );

    Serial.println(
        "STARTING RF ANTENNA SWEEP"
    );

    Serial.printf(
        "RUN ID = %lu\n",
        static_cast<unsigned long>(
            gRunId
        )
    );

    Serial.println(
        "================================\n"
    );

    for (
        size_t channelIndex = 0;
        channelIndex < NUM_TEST_CHANNELS;
        ++channelIndex
    ) {

        const uint8_t channel =
            TEST_CHANNELS[channelIndex];

        Serial.printf(
            "\n######## CHANNEL %u ########\n",
            channel
        );

        // ----------------------------------------------------
        // REF V TX
        // ----------------------------------------------------

        if (!runPhase(
                Phase::REF_V_TX,
                channel)) {

            Serial.println(
                "REF_V_TX FAILED"
            );

            continue;
        }

        // ----------------------------------------------------
        // REF H TX
        // ----------------------------------------------------

        if (!runPhase(
                Phase::REF_H_TX,
                channel)) {

            Serial.println(
                "REF_H_TX FAILED"
            );

            continue;
        }

        // ----------------------------------------------------
        // TEST ANTENNA TX
        // ----------------------------------------------------

        if (!runPhase(
                Phase::TEST_A_TX,
                channel)) {

            Serial.println(
                "TEST_A_TX FAILED"
            );

            continue;
        }

        // ----------------------------------------------------
        // TEST REFERENCE TX
        // ----------------------------------------------------

        if (!runPhase(
                Phase::TEST_R_TX,
                channel)) {

            Serial.println(
                "TEST_R_TX FAILED"
            );

            continue;
        }
    }

    setRadioChannel(
        CONTROL_CHANNEL
    );

    Serial.println(
        "\n================================"
    );

    Serial.println(
        "SWEEP COMPLETE"
    );

    Serial.println(
        "================================"
    );
}

One important correction before using this as the final instrument

I deliberately made the radio-control protocol more important than the particular CSI representation. The current ESP-IDF CSI API is stable in concept: register a callback, configure CSI, enable it, and preferably use promiscuous reception. 

However, the exact CSI buffer layout and number/location of tones varies among ESP32 generations. So I would not yet hard-code the 24 exported values as “frequency bins”. They are currently exported as sampled CSI complex bins. We should add a chip-specific CSI mapper after you tell me the exact ESP32 family.

There is another useful property of this architecture: we stay below the legacy ESP-NOW 250-byte payload limit, so the same protocol works even if one of the four boards is on an older ESP-IDF/Arduino-ESP32 stack. Current ESP-NOW v2 can carry more, but keeping control/results under 250 bytes avoids interoperability problems. 

I would change one thing in the sweep implementation

The current first-pass sequence is intentionally:

channel 1:
    V -> test
    H -> test
    test -> V/H
    test-ref -> V/H

channel 6:
    ...
channel 11:
    ...

For the actual antenna experiment, I would eventually use:

CH1 ... CH13

and make two complete sweeps, reversing the order of channels on the second sweep:

1,2,3,...,13
13,12,11,...,1

That helps identify slow environmental changes and gives us a way of detecting interference or drift rather than incorrectly attributing it to the antenna.

Also, esp_wifi_80211_tx() is a good choice here precisely because it permits raw action frames without establishing a normal Wi-Fi connection; Espressif documents it for action/non-QoS data frames and explicitly notes that the default raw transmit rate is 1 Mbps unless configured otherwise. 

The next firmware to implement should be the test-node master, because that completes the control protocol and lets us eliminate the getLocalSlaveResult() stub and make the four-radio experiment fully deterministic.
